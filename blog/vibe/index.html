Vibe Coding Setup 

October 25, 2026

One small server in Helsinki, a couple of containers, and an AI agent I talk to like a coworker. Ship first, refine while it's warm.

The Stack

pi — the coding agentv1.3.0

An AI pair programmer living in a terminal. It reads the code, edits the files, runs the commands — I steer with one-liners. This entire page was a vibe-coded delivery.

Hetzner — the machinehel1

Ubuntu 26.04, 2 vCPU, 4 GB RAM, sitting in Helsinki. Small, cheap, and more than enough when the compiler lives on someone else's datacenter.

Docker — the isolation

Every app gets its own container. The Adsplosion app runs on Node 22 behind docker compose up -d and nobody has to know or care what's inside.

Caddy — the front doorauto-TLS

A ~10-line Caddyfile reverse-proxies domains to containers and fetches TLS certificates automatically. HTTPS is not a feature, it's a default.

Cloudflare — the DNS

Nameserver pair holly + renan handle routing. Subdomains are a single record away, which is how this site got reorganized overnight.

Telegram — the control channel

The agent texts back. Pages, files, and status updates arrive as chat attachments from a pocket-sized terminal that never sleeps.
